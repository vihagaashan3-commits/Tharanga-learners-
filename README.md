# Learners Driving School website

Open `index.html` in a browser (double-click). No build step needed.

## Structure
- index.html, about.html, contact.html, event.html, road-signs.html, question-papers.html, registration.html
- css/style.css   – all custom styles (Bootstrap 5 loaded from CDN)
- js/data.js      – EDIT HERE: school name, phone, WhatsApp, branches, courses, events, signs, question papers
- js/main.js      – shared header and footer
- js/road-signs.js, js/question-papers.js, js/registration.js – page scripts
- images/         – put your logo and photos here

## Customise
1. Change name, phone, WhatsApp number and branches in js/data.js.
2. Add real question papers in PAPERS (js/data.js).
3. Replace emoji and car.svg with your photos in images/.
